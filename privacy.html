リフトログ プライバシーポリシー

制定日：2026年11月8日

リフトログ（以下「本アプリ」）は、筋トレの記録をつけるためのアプリです。本アプリでの個人情報・データの扱いを以下のとおり定めます。

1. 集めるデータ

本アプリは、利用者の情報を開発者や第三者のサーバーに送信しません。アカウント登録もありません。

2. 端末に保存するデータ

次のデータは、利用者の端末の中だけに保存されます。

  • トレーニングの記録（日付・種目・重量・回数・メモ）、ルーティン、表示の設定
  • 体重・体脂肪率の記録
  • 利用者が撮影または選択した体の写真

アプリを削除すると、これらのデータも端末から消えます。端末のバックアップ（iCloud バックアップなど）に含まれるかどうかは、利用者の端末の設定によります。

3. カメラと写真

カメラは、体の変化を見比べる写真を撮るときだけ使います。写真の選択は iOS の写真ピッカーを使い、利用者が選んだ写真だけを読み込みます。写真は端末の外には送りません。

4. 通知

休憩タイマーの終了を知らせるため、端末の中でローカル通知を使います。通知のために外部と通信することはありません。

5. バックアップファイル

「ファイルに書き出す」を選ぶと、記録を JSON ファイルとして書き出します。書き出したファイルの保存先や共有先は利用者が選びます。

6. 解析・広告

本アプリは、利用状況の解析ツール、広告、トラッキングを使いません。

7. お問い合わせ

GitHub の Issues からご連絡ください。

8. 改定

本ポリシーを変更するときは、このページで知らせます。
