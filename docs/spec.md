# リフトログ 仕様書（SwiftUI 移植用）

Web 版（`index.html`）の動きをそのまま書き起こしたもの。SwiftUI 版はこの仕様と同じ操作で同じ結果になることを目標にする。迷ったら `index.html` が正。

- 対象：`index.html`（2026-10-25 時点、コミット 34a30ea）
- 文言は Web 版のまま載せる。SwiftUI 版でも同じ文言を使う

## 1. 全体の構成

```
┌ ヒーロー（記録タブだけ）── ロゴ「LIFTLOG」／テーマボタン／まとめ（連続・今週・累計）
├ 下タブ ── 記録 / 履歴 / 推移 / 体 / ガイド
├ 各タブの画面
├ 休憩タイマー（画面下に固定）── 記録タブでは常に表示、数えている間はほかのタブでも表示
└ トースト（2.2 秒で消える）
```

- 開いていたタブは保存し、次回もそのタブで開く（`liftlog.tab`）
- タブを切り替えたら画面の先頭へスクロールする
- キーボード表示中（入力欄にフォーカス中）は下タブを隠す
- 確認ダイアログは「キャンセル／（任意で2つ目の選択肢）／実行」の3ボタン。外側タップ・Esc はキャンセル扱い

## 2. 画面ごとの仕様

### 2.1 ヒーローとまとめ（記録タブのみ）

| 表示 | 計算 |
| --- | --- |
| 連続 N 週 | 1日以上記録した週（月曜始まり）が何週続いているか。今週まだ記録がなければ先週から数える |
| 今週 N 回 | 今週の月曜以降に記録した日数（同じ日に複数あっても1回） |
| 累計 N 日 | 記録のある日数 |

まとめを押すと「部位ごとの今週」ダイアログを開く。

**部位ごとの今週ダイアログ**

- 上段：今週の合計セット数と合計ボリューム（kg）、それぞれ先週との差（`+N` / `−N` / `±0`）
- 部位ごとの行（胸・肩・背中・腕・腹・脚、記録があれば「その他」）：今週と先週のセット数の棒（最大値で正規化、今週は塗り、先週は枠）、今週のセット数、`Nkg（先週 Nkg）`、`先週比 ±N`
- 数え方：部位は種目名から引く（既定の種目＋自分で足した種目）。回数が 0 のセットは数えない。ボリューム = Σ(重量 × 回数)、自重は 0kg
- 注記：`{月曜の日付}から今日までの記録。塗りつぶした棒が今週、枠だけの棒が先週のセット数です。ボリュームは重量×回数の合計で、自重の種目は0kgになります。` ＋部位不明の種目があれば `部位が決まっていない種目（A・B）は「その他」に数えています。`

### 2.2 記録タブ

上から順に：

1. **日付**（日付入力）と、過去の記録を編集中なら「過去の記録を編集中」の表示
2. **入力中の種目カード**（下書き）
3. **ルーティン**：見出し＋「作成・編集」リンク、ルーティンのチップ（名前＋「N種目」）。種目が1つでも入ったら見出しとチップは隠し、「入力中の種目をルーティンとして保存」ボタンだけ出す。ルーティンが無いときの文言：`よくやる種目の組み合わせを保存しておくと、ここからまとめて追加できます。`
4. **種目を追加**：見出し＋「表示する種目を選ぶ」リンク、部位チップ（胸・肩・背中・腕・腹・脚）、選んだ部位の種目チップ（アイコン付き）、自由入力欄（placeholder「その他」）＋「追加」
5. **メモ**（placeholder「調子、睡眠、フォームの気づきなど」）
6. **保存**（編集中は「変更を保存」）／**入力をクリア**

**種目カード**

- 見出し：開閉トグル（▼）＋種目アイコン＋種目名、開いていてガイドがあれば「やり方」リンク、開いていれば「×」（種目を外す。確認なし）
- 閉じたカードは種目名だけ。新しい種目を追加すると、既存のカードはすべて閉じる
- 本文：
  - 前回の記録があれば「前回をコピー」リンク、無ければ `この種目は初めての記録です`
  - セット表：`SET`（01, 02…）／`重量（kg）`（小数、step 0.5）／`×`／`回数`（整数）／`済`（チェック）／削除
  - 「＋ セット追加」：直前のセットの重量・回数をコピーして1行足し、その回数欄にフォーカス
- 「済」チェック：入力中の目印。オンにした瞬間に休憩タイマーを（選択中の秒数で）始め直す。保存される中身には影響しない

**種目の追加（`addExercise`）**

- 前回の記録（後述 `lastSession`）があれば、そのセットの重量・回数を入れた状態で追加。トースト `{種目}を追加（前回の内容を入力済み）`
- 無ければ空のセット1行。トースト `{種目}を追加`
- 同じ種目を2回追加することは止めていない（ルーティン呼び出し時だけ重複を除く）

**前回の記録（`lastSession(name)`）**

記録を「日付の新しい順 → 作成時刻の新しい順」に見て、編集中の記録自身と、下書きの日付より後の記録を除き、その種目を含む最初の記録のセット。

**保存**

1. 各セットを `w = 数値 || 0`、`r = 四捨五入した整数 || 0` に直し、`r > 0` のセットだけ残す。セットが残らない種目は捨てる
2. 何も残らなければトースト `回数が入ったセットがありません。回数を入れてから保存してください` で中止
3. 保存内容：`date`、`exercises`、`memo`（前後の空白を除く）、`createdAt`（編集時は元の値）、`updatedAt`
4. トースト：新規は `{M/D（曜）}の記録を保存しました`、編集は `変更を保存しました`
5. 下書きを空にして履歴タブへ移る
6. 失敗時：`保存できませんでした。端末の空き容量やプライベートブラウズでないかを確かめてください`

**入力をクリア**：確認 `入力をクリアしますか？`／`入力中の種目・セット・メモが消えます。保存済みの記録はそのまま残ります。`／[クリア] → トースト `入力をクリアしました`

**下書き**

- 入力のたびに保存し、アプリを開き直しても残る
- 何も入っていない下書き（種目なし・メモなし・新規）は、起動時と画面に戻ったときに日付を今日に戻す

### 2.3 ルーティン

ルーティンは種目名の並びだけを持つ（重量・回数は呼び出し時に前回の記録から入る）。

**呼び出し（記録タブのチップ）**

- 種目が空のルーティン：トースト `「{名前}」には種目が入っていません。「作成・編集」から足してください`
- 入力中の種目があれば確認：`「{名前}」を呼び出しますか？`／`入力中の種目がNつあります。置き換えると、入力中のセットは消えます。`／[置き換える]・[後ろに足す]
- 下書きにすでにある種目は飛ばして追加。トースト `「{名前}」のN種目を追加しました` または `「{名前}」の種目はすべて入っています`

**作成**

- 「＋ 新しいルーティン」（空）、記録タブの「入力中の種目をルーティンとして保存」、履歴の「ルーティンにする」の3か所から作れる。後の2つはトースト `ルーティンを作りました。名前は書き換えられます`
- 作ったらすぐ編集ダイアログを開き、名前欄を選択状態にする
- 名前の初期値：種目の部位が1〜2種類なら `胸トレ` / `胸・腕トレ`、それ以外は `ルーティン`。同名があれば ` 2`, ` 3`… を足す
- 種目は重複を除く

**編集ダイアログ「ルーティン」**

- ルーティンごとに：名前（最大30文字、空にしたら元に戻す）、種目の並び（左端のつまみでドラッグ並び替え、キーボードでは上下キー）、各種目の削除、種目追加欄（候補＝既定の種目＋自分で足した種目＋記録にある種目、placeholder「種目名」）、「このルーティンを削除」
- 同じ種目の追加：トースト `{種目}はすでに入っています`
- 削除確認：`「{名前}」を削除しますか？`／`ルーティンだけを消します。保存済みの記録はそのまま残ります。`／[削除] → トースト `ルーティンを削除しました`

### 2.4 記録画面に出す種目（ダイアログ）

- 注記：`チェックを外した種目は「種目を追加」に出なくなります。ガイドからはいつでも追加できます。`
- 部位チップ（記録タブの部位選択と連動）、既定の種目のチェックリスト、「自分で足した種目」（削除ボタン付き）、追加欄（最大30文字、placeholder `{部位}に種目を足す`）
- 追加のルール：
  - 別の部位にある名前 → トースト `{種目}は{部位}にあります`
  - この部位の既定の種目 → 非表示を解除してトースト `{種目}を表示に戻しました`
  - すでに足してある → トースト `{種目}はすでに入っています`
  - それ以外 → この部位に足す
- 部位の種目がすべて非表示のとき、記録タブには `{部位}の種目はすべて非表示です。「表示する種目を選ぶ」から選んでください。`

### 2.5 休憩タイマー

- 秒数の選択肢：60 / 90 / 120 / 180（既定 90、保存する）
- 待機中：`休憩（秒）`＋秒数チップ＋「開始」
- 計測中：`休憩`＋残り `m:ss`＋「−15秒」「＋15秒」「止める」＋進捗バー
- 残り時間は終了時刻から毎回計算する（`{ end, total }` を保存し、アプリを開き直しても続きから）
- ±15秒は終了時刻をずらし、`total = max(total, end − now)`
- 終了時：
  - 終了から 60 秒以上たってから画面に戻った → 鳴らさずトースト `休憩は終わっています`
  - それ以外 → バイブ（Android のみ）＋ビープ（880Hz の矩形波を 0.35 秒間隔で3回）＋トースト `休憩終了。次のセットへ`
- 記録タブを開いている間とタイマー計測中は画面を消さない

### 2.6 履歴タブ

記録が無いとき：`まだ記録がありません。「記録」タブで種目とセットを入れて保存すると、ここに日付ごとに並びます。`

上から：

1. **カレンダー**：`YYYY.MM` と前後の月ボタン（今月より先へは進めない）、月曜始まり、今日に印、記録のある日はボタン。押すとその日の記録カードまでスクロールして一時的に強調（一覧に出ていなければ全件表示に切り替える）
   - 下に `N週連続で週G回以上` と目標回数チップ（週1〜週5、既定 週2、保存する）
   - 連続の数え方：週ごとの記録日数が G 以上の週が何週続いているか。今週がまだ G 未満なら先週から数える
2. **鍛えた部位**：期間チップ（1週間 / 4週間 / 3か月 = 7 / 28 / 91 日、保存する）、人体図（前・後）、部位を押すと `{筋肉名} N.N セット／週`（同じ部位か外を押すと消える。未選択時は `図の部位を押すと名称が出ます`）、部位のランキング（1週間あたりセット数の多い順）、凡例 `数字と色の濃さは1週間あたりのセット数：1〜 4〜 8〜 12〜`、注記 `補助で使う部位は0.5セットとして数えています。`＋部位不明の種目があれば `部位が登録されていない種目（A・B）は含みません。`。期間に記録が無ければ `この期間の記録はありません。`
3. **サンプルの案内**（サンプルの記録があるとき）：`「サンプル」の付いた記録は見本です。自分の記録をつけ始めたら消してください。`＋「サンプルを削除」（確認 `サンプルを削除しますか？`／`最初に入っているサンプルの記録をすべて消します。自分で付けた記録は消えません。`）
4. **記録の一覧**：新しい順に直近 5 件。月が変わるところに `YYYY.MM` の見出し。残りは「それより前の記録 N件を表示」で全件に。タブを開き直したら直近 5 件に戻す
5. **バックアップ**（後述）

**記録カード**

- 見出し：`M/D（曜）`＋サンプルなら「サンプル」バッジ、右に `N種目 · Nセット`
- 種目ごとに：種目名＋自己ベストなら「自己ベスト」バッジ、セットの要約（`60×8 · 60×7 · 自重×10`）
- 小さい人体図（その日の部位、濃さの段階 3 / 5 / 8 セット）
- メモ
- 「ルーティンにする」「編集」「削除」
  - 編集：同じ記録を編集中ならそのまま記録タブへ。下書きに中身があれば確認 `{日付}の記録を編集しますか？`／`入力中の種目・セット・メモは消えます。保存済みの記録はそのまま残ります。`／[編集する]
  - 削除：確認 `{日付}の記録を削除しますか？`／`削除した記録は元に戻せません。`／[削除] → トースト `記録を削除しました`

### 2.7 バックアップ（履歴タブの下）

- 説明：`記録はこの端末の中だけに保存されます。機種変更の前や、ときどきの控えとしてファイルに書き出しておいてください。読み込むと、同じ記録は上書きされ、それ以外は追加されます。体重の記録、ルーティン、記録画面に出す種目の設定も含まれますが、体の写真は含まれません。`
- 「ファイルに書き出す」：`liftlog-YYYY-MM-DD.json` を共有シートで渡す（使えなければダウンロード）。トースト `バックアップを書き出しました`
- 「ファイルから読み込む」：形式は 4.3 節。成功トースト `N件の記録と N日分の体重、N件のルーティンを読み込みました`（含まれるものだけ）、失敗 `読み込めませんでした。このアプリで書き出したファイルを選んでください`

### 2.8 推移タブ

上部：種目ボタン（`{種目名} N回`）、指標の切り替え「推定1RM / 最大重量」（保存する）。体重を選んだときは指標の代わりに期間「1か月 / 3か月 / すべて」（保存する）。

**種目を選ぶダイアログ**：先頭に「体 › 体重（N日）」、続いて部位ごと（胸・肩・背中・腕・腹・脚・その他）に記録のある種目を記録回数の多い順で `{種目} N回`。選択中の行までスクロールして開く。

**種目の推移**

- 記録が無いとき：`記録が2回以上たまると、種目ごとに重量の伸びがグラフで見られます。体重は上のボタンから記録できます。`
- 選択中の種目が記録に無ければ、記録回数が一番多い種目を選ぶ
- 1回の記録の値：推定1RM = その日のセットの推定1RM の最大、最大重量 = その日のセットの重量の最大
- カード：
  - 重量のある種目：`推定1RM ベスト`（値・日付）、`最大重量`（値・日付）、`記録した回数`（N回・`初回 {日付}`）
  - 自重種目（最大重量が 0）：`最高回数`、`記録した回数`
- グラフ（重量のある種目のみ）：折れ線＋面、点、最大値の点を赤く大きく、最新の点を大きく、右端に最新値。横軸ラベルは最初・真ん中・最後の日付。縦軸は値の範囲に上下 12% の余白、目盛りは 1/2/5×10^n の刻みで約4本
- 自重種目は `自重種目のため重量のグラフはありません。`
- 注記：`推定1RM はエプリー式（重量 ×（1 + 回数 ÷ 30））で、その日いちばん高いセットの値です。赤い点がベスト。`
- 「最近のセッション」：新しい順に 6 件、`日付`・`Nセット`・セットの要約

**体重**

- 入力フォーム：日付（既定は今日。日付を変えるとその日の記録を入れる）、体重（kg、step 0.1、必須）、体脂肪率（%・任意）、保存
  - 体重 0 以下ならトースト `体重を入れてください`
  - 値は小数1桁に丸める。トースト `{日付}の体重を保存しました`（既存なら `上書きしました`）
- 記録が無いとき：`毎日同じ条件（朝起きてトイレのあと・食事の前など）で量ると、増減の傾向がつかみやすくなります。`
- カード：`最新`（体重・日付・体脂肪）、`期間の増減`（期間の最後と最初の7日平均の差、`7日平均で比べた値`）、`記録した日数`（期間内の日数・初回）
- グラフ：体重の折れ線＋7日移動平均の点線（ベストの赤い点は出さない）。注記 `点線は7日間の移動平均（その日までの7日間に記録した体重の平均）です。毎日の増減より、こちらの傾きを見てください。`
- 「記録」一覧：新しい順。日付（今年以外は `YY/` を前に付ける）、体重、体脂肪、「修正」（フォームにその日を入れてフォーカス）、「削除」（確認 `{日付}の体重を削除しますか？`／`削除した記録は元に戻せません。同じ日の体の写真に表示される体重も消えます。`）

### 2.9 体タブ（写真）

- 「撮影する」「写真から選ぶ」
- 選んだ写真は長辺 1080px の JPEG（品質 0.8）に縮めて「写真を保存」ダイアログへ：プレビュー、日付（既定 今日、変えるとその日の体重を入れる）、体重（kg・任意、既定はその日の体重の記録）、メモ（任意、placeholder `朝・食前など、撮った条件`）
  - 保存すると写真を保存し、体重が入っていれば体重の記録にも書く（体脂肪率は残す）。トースト `{日付}の写真を保存しました`
  - 読み込み失敗：`この写真は読み込めませんでした`
- 写真が無いとき：`まだ写真がありません。同じ場所・同じ姿勢で定期的に撮っておくと、見た目の変化を並べて比べられます。`
- **ビフォー・アフター**（写真が2枚以上のとき）：一覧の「比較」で選んだ2枚を、古い方をビフォー、新しい方をアフターに並べる。空き枠は `一覧の「比較」で写真を選んでください`。2枚そろうと `N日間・体重 +N.N kg`。「選択を解除」。3枚目を選ぶと最初に選んだものが外れる。2枚そろったら先頭へスクロール
- 一覧：日付の新しい順（同日は作成の新しい順）の格子。`YYYY/M/D（曜）`、サンプルバッジ、体重（その日の体重の記録。無ければ写真に付いた古い値）、メモ、「比較」「削除」（確認 `{日付}の写真を削除しますか？`／`削除した写真は元に戻せません。`）
- サンプルの案内：`「サンプル」の付いた写真は見本です。自分の写真を撮り始めたら消してください。`＋「サンプルを削除」
- 注記：`写真はこの端末の中だけに保存され、外には送りません。容量が大きくなるため、履歴の「バックアップ」には含まれません。`

### 2.10 ガイドタブ

- 部位チップ、その部位の既定の種目のうちガイドがあるもののカード（フィニッシュの姿勢の図、「前から／横から」ラベル、種目名、主に効く筋肉）
- カードを押すと詳細ダイアログ：
  - 種目名、`器具：{gear}`
  - ① スタート ／ ② フィニッシュの図（フィニッシュにはスタートの姿勢を薄く重ね、動く向きを矢印で示す）

## 4. 保存データ

### 4.1 localStorage

| キー | 形 | 既定値 |
| --- | --- | --- |
| `liftlog.workouts` | `{ [id]: Workout }` | `{}` |
| `liftlog.draft` | `Draft` | 空の下書き |
| `liftlog.routines` | `Routine[]` | `[]`（初回だけ見本） |
| `liftlog.exset` | `{ hidden: string[], own: { [部位]: string[] } }` | `{}` |
| `liftlog.bodyweight` | `{ "YYYY-MM-DD": { w: number, fat?: number } }` | `{}` |
| `liftlog.rest` | `{ end: エポックms, total: ms } \| null` | `null` |
| `liftlog.restSec` | 60 / 90 / 120 / 180 | 90 |
| `liftlog.tab` | `log` / `history` / `progress` / `body` / `guide` | `log` |
| `liftlog.metric` | `e1rm` / `max` | `e1rm` |
| `liftlog.hp` | 7 / 28 / 91 | 7 |
| `liftlog.goal` | 1〜5 | 2 |
| `liftlog.bwRange` | `1m` / `3m` / `all` | `1m` |
| `liftlog.skin` | `iron` / `plate` / `clock` | `iron` |
| `liftlog.seeded` | 見本の記録を入れた版（現在 2） | `false` |
| `liftlog.rtSeeded` | 見本のルーティンを入れたか | `false` |
| `liftlog.photoSeeded` | 見本の写真を入れたか | `false` |

```ts
type Workout = {
  date: "YYYY-MM-DD";
  exercises: { name: string; sets: { w: number; r: number }[] }[]; // w=0 は自重、r は 1 以上の整数
  memo: string;
  createdAt: number; // エポック ms（見本は 0, 1, 2…）
  updatedAt?: number;
  example?: true;    // 見本
};
// id は "w-" + base36 時刻 + 乱数4文字。見本は "sample-N"

type Draft = {
  id: string | null;  // 編集中の記録の id。新規は null
  date: "YYYY-MM-DD";
  exercises: { name: string; sets: { w: string; r: string; done?: boolean }[]; closed?: boolean }[];
  memo: string;
};

type Routine = { id: string; name: string; exercises: string[] }; // id は "r-…"、見本は "r-sample-N"
```

記録の並び順：日付の新しい順 → `createdAt` の新しい順。

### 4.2 IndexedDB（写真）

DB `liftlog`（版 1）、ストア `photos`（キー `id`）：

```ts
type Photo = {
  id: string;        // "p-…"、見本は "sample-pN"
  date: "YYYY-MM-DD";
  memo: string;
  blob: Blob;        // JPEG、長辺 1080px
  createdAt: number;
  example?: true;
  weight?: number;   // 古い形式。起動時に体重の記録へ移し、移せたものは消す
};
```

### 4.3 バックアップファイル

```json
{
  "app": "liftlog",
  "version": 1,
  "exportedAt": "ISO 8601",
  "workouts": { "[id]": Workout },
  "bodyweight": { "YYYY-MM-DD": { "w": 70.2, "fat": 15.1 } },
  "routines": [Routine],
  "exset": { "hidden": [], "own": {} }
}
```

読み込みのルール：

- `app !== "liftlog"` または `workouts` が無ければ失敗
- 記録：`date` が文字列で `exercises` が配列のものだけ。同じ id は上書き、それ以外は追加
- 体重：日付が `YYYY-MM-DD` で `w > 0` のものだけ。同じ日は上書き
- ルーティン：形の正しいものだけ。同じ id は置き換え、無いものは後ろに追加
- 種目の表示設定：ファイルの内容で丸ごと置き換え
- 写真は含まない

## 5. 計算

| 名前 | 定義 |
| --- | --- |
| 推定1RM | `w ≤ 0 または r ≤ 0` → 0、`r = 1` → `w`、それ以外 `w × (1 + r / 30)` |
| 週の始まり | 月曜 |
| 自己ベスト（履歴のバッジ） | 古い順に見て、その日の推定1RM の最大が、それまでのベストを超えた種目。その種目の初回は付かない |
| 部位別セット数（鍛えた部位） | 記録の各種目について、ガイドの `main` の筋肉に +セット数、`sub` に +セット数 × 0.5。ガイドの無い種目は数えない |
| 1週間あたりセット数 | 期間のセット数 × 7 ÷ 期間の日数 |
| 色の濃さ（0〜4） | 0 ならば 0、それ以外は 1 + (しきい値以上の数)。鍛えた部位は [4, 8, 12]、記録カードの小さい図は [3, 5, 8] |
| 体重の7日移動平均 | その日を含む直近7日間（日付 −6 日〜当日）に記録した体重の平均。記録の無い日は数えない |
| 数字の表示 | 重量・体重は小数1桁まで（末尾の .0 は付けない）、ボリュームは整数で桁区切り |
| 日付の表示 | `M/D（曜）`、グラフの横軸は `M/D` |

## 6. 初期データ（初回起動時のみ）

- **見本の記録**：12週ぶんの Push / Legs / Pull（ベンチプレス・サイドレイズかダンベルフライ・プレスダウン／スクワット・レッグカール・カーフレイズ／デッドリフト・懸垂・ベントオーバーロウ）。7週目はデロード、2日分は休み。自分の記録がある端末には入れない。生成の仕方は `seedSamples` を参照
- **見本のルーティン**：胸トレ・肩トレ・背中トレ・脚トレ・腕トレ・腹トレ。ルーティンを持っている端末には入れず、消しても入れ直さない
- **見本の写真**：84・56・28・1 日前の体のシルエット画像（その場で描く）と体重 74.2 / 73.1 / 71.8 / 70.6kg
